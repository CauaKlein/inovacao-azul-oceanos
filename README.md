# 🌊 Soluções Sustentáveis para Oceanos com Tecnologia  
### Inovação Azul 2024 | FIAP  

---

## 📌 Visão Geral  
Este projeto foi desenvolvido no contexto do desafio **Inovação Azul 2024**, promovido pela FIAP, com o objetivo de criar soluções tecnológicas voltadas à sustentabilidade dos oceanos.

A proposta aborda problemas críticos relacionados à degradação ambiental marinha, utilizando tecnologia e inovação para promover uma **Economia Azul sustentável**, equilibrando fatores ambientais, sociais e econômicos.

---

## 🌎 Contexto do Problema  
Os oceanos enfrentam desafios significativos que impactam diretamente o planeta:

- Poluição marinha (especialmente plásticos)  
- Destruição de habitats marinhos  
- Mudanças climáticas  
- Exploração excessiva de recursos naturais  

Esses fatores afetam não apenas o meio ambiente, mas também a economia global e a qualidade de vida das populações.

---

## 🎯 Objetivo  
Desenvolver uma solução tecnológica capaz de:

- Promover a conservação dos oceanos  
- Reduzir impactos ambientais  
- Melhorar a gestão dos recursos marinhos  
- Incentivar práticas sustentáveis  

---

## 💡 Solução Proposta  
O projeto propõe uma solução baseada em tecnologia para monitoramento, análise e apoio à tomada de decisão no contexto marinho.

### 🔍 Possíveis abordagens:
- Monitoramento ambiental com sensores  
- Uso de dados e inteligência artificial  
- Análise de poluição e impacto ambiental  
- Apoio à gestão sustentável dos oceanos  

---

## ⚙️ Funcionalidades do Sistema  
- 📊 Análise de dados ambientais  
- 🌊 Monitoramento de condições marinhas  
- 📈 Visualização de informações e indicadores  
- 🤖 Apoio à tomada de decisão  
- 💻 Interface web interativa (quando aplicável)

## 🧩 Arquitetura do Projeto  

O projeto contempla diferentes camadas de desenvolvimento:

### 🗄️ Modelagem de Banco de Dados  
- Modelo Entidade-Relacionamento (MER)  
- Normalização de dados  
- Relacionamentos entre entidades  

### ☕ Backend (Java)  
- Desenvolvimento orientado a objetos  
- Criação de classes com atributos e métodos  
- Uso de:
  - Herança  
  - Associação  
  - Agregação e composição  
- Programa de teste para validação das classes  

### 🎨 Front-End / Protótipos  
- Desenvolvimento de interfaces (HTML/CSS)  
ou  
- Protótipos utilizando ferramentas como Figma
